# 5 · KI & Lernen

## Anbieter (`src/lib/ai.ts`)

- **Google Gemini** (`generateContent`, JSON-Antwort) und **OpenRouter** (OpenAI-kompatibel).
  Reihenfolge nach Einstellung; fällt einer aus (429, Fehler), wird der andere versucht.
- `askJSON(system, user, temperature, cfg)` → `{ json, provider }`. Kaputtes JSON bekommt einen zweiten
  Versuch beim selben Anbieter (`extractJSON` wirft dann `AIError`).
- Woher die Schlüssel kommen: Browser → `getAI()` aus `settings.ts` (nur dieses Gerät);
  Server → `serverAI()` aus der `.env` (`src/server/http.ts`).
- Modelle, Kosten, Bild/Video und Ausbaustufen: [`../KI-PLAN.md`](../KI-PLAN.md).

## Prompts (`src/lib/prompts.ts`)

| Funktion | Zweck |
|---|---|
| `generateCard(brief, extra, cfg, opts)` | ganze Karte: Szenen, Kino-Texte, Kopfzeile, Reaktionen |
| `rewriteScene(brief, scene, wunsch)` | eine Seite neu (der Gutschein wird **nie** mitgeschickt) |
| `restyle(theme, effects, wunsch)` | Design per Wunsch, inkl. Effekt-Rezepten; danach `fixContrast` |
| `restyleOffline(data, wunsch)` | ohne KI: Stichwortliste („matrix“, „ballons“, „schnee“ …) |
| `testAI()` | „KI testen“ in den Einstellungen |

**Datenschutz-Regeln (nicht verhandelbar):**
1. Der **Name** der Person geht nie an die KI. Sie schreibt `{{name}}`; der Brief enthält nur Beziehung,
   du/Sie, Anlass, Stimmung, Stichworte, Geschenk. In der Schnell-Karte wird der Name in den Antworten
   durch „die Person“ ersetzt (`questions.ts → answersToNotes`).
2. **Gutscheine** (Codes, Bilder, PDFs) gehen nie an die KI und bleiben bei jeder Neufassung erhalten
   (`cardbase.ts → withGenerated`).
3. KI-Antworten werden wie fremde Daten behandelt und vollständig geprüft (`validate.ts`).

## Effekt-Rezepte – „die KI erfindet Effekte“

Die KI darf keinen Code schreiben (unzuverlässig und unsicher), aber Rezepte:
`{ emoji: ["🎈","🎉"], motion: "rise"|"fall"|"float"|"swirl"|"pop", amount, size }`.
`normalizeParticles` lässt nur kurze Symbole ohne Buchstaben/Markup durch; gezeichnet wird mit eigenem,
geprüftem Code im Kartenskript. So entstehen Ballons, Schnee, Blütenwirbel, Fußbälle …

## Lernen aus Bewertungen (`src/lib/learning.ts`)

Gespeichert werden nur **Merkmale** (Design, Stil, Anlass, Beziehungsgruppe, Schreibstil-Variante,
Gründe) – nie Namen oder Stichworte. Optional ein kurzer Textauszug ohne Namen als Stil-Vorbild.

| Funktion | Was sie lernt |
|---|---|
| `chooseVariant` | Schreibstil A/B: abwechselnd, bis beide 5 Bewertungen haben, dann zu 85 % der bessere |
| `rankPresets` / `suggestPreset` | Designs, die für Anlass + Beziehungsgruppe gut ankamen |
| `pickSamples` | gelungene Formulierungen als Vorbild im Prompt |
| `MAX_RETRIES` | nach 👎 bekommt die KI bis zu 2 weitere Versuche (`RatingBar`) |

Ein 👎 zählt pro Fassung nur einmal (`RatingBar.tsx`).

## Schnell-Karte (`src/lib/questions.ts`)

`questionsFor(beziehung, anlass)` wählt zwei freundliche Fragen mit Antwort-Ideen; `suggestMood` und
`suggestPreset` ergänzen Stimmung und Design.
